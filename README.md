## Design
Black-and-white, academic + computational-biology theme:
- **Serif (Fraunces)** for headings, **monospace (JetBrains Mono)** for
  labels/metadata, **sans (Inter)** for body text.
- Signature hero graphic: a brain rendered as a neural-network graph, with
  its lower connections resolving into circuit traces — the biology ↔
  computation theme carried through the whole site (terminal-style `>`
  eyebrows, `$` prompts on publication years, a dark "console" section).
- All colour is grayscale; no accent colour is used anywhere.

## Publish on GitHub Pages
Create a public repository named `YOURUSERNAME.github.io`, upload all files
from this folder, then go to:
Settings → Pages → Deploy from a branch → main → /(root)

Your site will be available at `https://YOURUSERNAME.github.io`.
