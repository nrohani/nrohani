# Narjes Rohani — Academic Website

Static HTML/CSS/JS site for Narjes Rohani.

## Current structure

- Home
- Research
- Publications
- News
- Teaching
- Public engagement
- CV
- Images
- Contact

The Tools page has been removed from the visible site for now. The former About page has been simplified into Contact.

## Images

Personal images should be placed in `assets/images/personal/` as:

- `profile.jpg`
- `talk.jpg`
- `event.jpg`

The gallery uses a fixed, compact image height so photographs stay readable without becoming oversized.
